Database Systems · Performance Engineering

High-Throughput MySQL Architecture & Query Optimization

Database Engineering · High Concurrency · Munich, Germany

In high-scale consumer applications, database response times directly dictate conversion rates and user happiness. At CHECK24, our relational database clusters process continuous streams of comparison calculations, inventory matches, and real-time user selections.

Over multiple years of hands-on database engineering and architectural oversight, I led crucial initiatives to optimize relational schema structures, untangle slow queries, and ensure predictable latency even during peak consumer campaigns (e.g. seasonal traffic surges).

Technical Focus Areas

  • Index Tuning & Execution Plans: Analyzed EXPLAIN execution plans, identified full table scans and temporary tables, and introduced covering composite indexes that slashed query execution times from hundreds of milliseconds to single-digit milliseconds.
  • Zero-Downtime Schema Migrations: Coordinated large-scale table refactorings and column modifications without service interruption or table locking, ensuring uninterrupted consumer access.
  • Lock Contention & Transaction Boundaries: Audited InnoDB lock graphs and reduced transaction scopes to eliminate deadlocks in high-concurrency booking and matching pipelines.
  • Query Profiling & Developer Tooling: Set up automated query profiling and slow-query alerting, providing team developers with early feedback loops during code reviews before database changes hit staging or production.
